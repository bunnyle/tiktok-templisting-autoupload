# TikTok Live小助手

在 TikTok LIVE Manager 自動填寫並上架 Temporary listing 的 Tampermonkey 腳本。

## 安裝（只需一次）

1. 在 Chrome 安裝 [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)。
2. 打開 `chrome://extensions` → Tampermonkey →「詳細資料」→ 開啟 **允許使用者指令碼（Allow User Scripts）**。
3. 點這個連結，在 Tampermonkey 彈出的頁面按 **安裝**：

   **👉 [安裝 / 更新腳本](https://raw.githubusercontent.com/bunnyle/tiktok-templisting-autoupload/main/tiktok-templisting-autoupload.user.js)**

4. 打開或刷新 [LIVE Manager](https://shop.tiktok.com/streamer/live/product/dashboard?tool_tab=auction)，左下角出現「一鍵上架」面板就完成了。

## 更新

Tampermonkey 會自動檢查新版本並更新。想馬上更新：點 Tampermonkey 圖示 →「檢查使用者指令碼更新」，或再點一次上面的安裝連結。

## 圖片庫

部分類目要求上傳商品圖片。在「商品庫 → 圖片庫」上傳圖片：
- 上傳時會先彈出**正方形裁剪框**（拖動、放大，按「確定」；或「不裁剪」）。圖片上的 ✂ 可以重新裁剪。
- 點 ★ 設定**預設圖片**：類目要求圖片、商品又沒指定時自動使用。
- 在商品「編輯」裡可以指定每個商品用哪一張圖片（有指定就一定會上傳）。
- 上架時 TikTok 若彈出「Edit image」，會自動按 Done。
- 類目要求圖片但沒有可用的圖片時，該商品會先跳過，最後提示手動處理。

圖片存在瀏覽器裡，「下載完整備份」會一起打包。

## 直播檢測

「直播檢測」分頁 → 按「開始檢測」（直播時保持 LIVE Manager 頁面開著）：
- 畫面下方出現「won!」就記錄：拍賣編號、完整 listing 名稱、客人、成交價、得標時間。
- 得標後指定時間內（預設 3 分鐘），該客人在聊天區的每句留言都連同時間記到這一單；同時可以有很多單在等回覆。
- 聊天區出現「won auction item」時標記為已付款。
- 「匯出 CSV」下載全部記錄。重新整理頁面後會自動繼續檢測。

## 匯出記錄

「⬇ 匯出並清空」會把訂單存成 CSV，文件名按場次和日期（例如 `TikTokLive_PT1_1110_2026.csv`），然後清空記錄，下一場重新開始。

## 評論大窗（給主播看）

「直播檢測」分頁按「⧉ 彈出評論窗」，會開一個獨立窗口，只顯示評論區：可以拖到第二個螢幕或電視，按「全螢幕」放大。也可以按「📌 置頂小窗」（需要 Chrome 116 或以上），開一個永遠浮在最上面的小窗。

- 窗口上方的滑桿調字體大小（14–64）；可切換深色 / 淺色。
- 每個客人固定一個顏色；得標的客人前面有紅色 #編號，整行紅色底。
- 主播自己的留言是藍色底（發自動公告時會自動認出主播帳號，也可以在面板填寫）。
- 「只看得標客人」濾掉閒聊；「付款通知」顯示誰已付款。
- 頂部顯示當前拍賣（編號、價錢、領先 / 得標的人）。
- 窗口有自己的語言選擇（繁體 / 简体 / English），和面板分開設定。
- 「🚫 過濾」：包含指定句子的留言不顯示（例如 giveaway 要求客人留的話），每行一句；也可以把滑鼠移到留言上按 🚫 加入。被過濾的留言也不會記到訂單回覆。
- 上方搜尋框可以搜客人名字、留言內容或 #編號（Esc 清除）。
- 點客人名字，下方會顯示他之前的發言（先顯示最近 5 條，按「顯示更早」看全部）。
- 預設最新留言在上面，新留言從頂部滑入；取消「最新在上面」就變回最新在下面。
- 捲動去看舊留言時會暫停自動捲動，按「新留言」回到最新。

第一次按時如果 Chrome 擋住彈出窗口，請在網址列右邊允許 shop.tiktok.com 彈出窗口。TikTok 那個窗口不要最小化。

## 自動公告

「自動公告」分頁：新增多條公告（每條最多 100 字，可單獨開關），設定間隔（最少 1 分鐘，可隨機浮動 ±15%），按「開始自動公告」。
- 開啟的公告隨機輪流，一輪內不重複，連續兩次不會同一條。
- 「避開重複評論」：最近發過的會自動換成變體（句尾加 . / .. 、!! 、改空格）；TikTok 沒接受時自動換下一個變體再試。
- 你正在聊天框打字時會先等你發完。每條都有「立即發送」。

## 換電腦

舊電腦：商品庫 → 匯入 · 備份 · 工具 →「下載完整備份」。
新電腦：安裝腳本後 →「匯入備份檔」，商品庫、類目庫、圖片庫和設定都會搬過去。

## 留言直接讀取

留言現在直接從 TikTok 收到的網路資料讀取（評論窗狀態列顯示「直接讀取」），不受畫面有沒有畫出來、視窗有沒有被遮住影響；連線沒有資料時自動退回「看畫面」。得標和付款紀錄仍然看畫面。

## 網路診斷

「直播檢測」分頁的「網路診斷」會下載一個 `tiktok-net-diag-….txt`：裡面是 TikTok 頁面收到的網路資料樣本（只記在這一頁的記憶體，按了才存檔，不會自動傳到任何地方），用來找出留言和得標資料的來源，方便之後改成直接讀網路資料、不靠畫面。檔案裡有畫面上的客人名稱和留言。
